# Расписание МАИ v4.1.6

Локальная веб-утилита для расписаний групп, поиска преподавателей и анализа занятости аудиторий.

## Что важно в этой версии

`database_v413.json` не хранится в репозитории и собирается локально из актуального публичного источника МАИ:

- список групп: `https://public.mai.ru/schedule/data/groups.json`;
- расписание каждой группы: `https://public.mai.ru/schedule/data/<md5-группы>.json`;
- период по умолчанию: 31.08.2026–31.01.2027 (3-й семестр / осень 2026/27).

После сборки `database_v413.json` содержит все группы, для которых МАИ отдал занятия в выбранном периоде. Рядом автоматически создаётся `database_v413.js` для режима `file://`.

## Windows — обычный запуск

Запусти:

```bat
start.bat
```

На первом запуске программа:

1. установит зависимости;
2. скачает `groups.json`;
3. скачает расписания всех групп параллельно;
4. соберёт полную `database_v413.json`;
5. создаст `database_v413.js`;
6. откроет интерфейс на `http://127.0.0.1:8765/`.

На следующих запусках полная база не пересобирается, если `database_status.json` помечает её как актуальную и полную.

## Только обновить базу

```bat
update_database.bat
```

Этот файл принудительно пересобирает полный JSON текущего семестра.

## Прямое открытие `index.html`

Работает без CORS-крэша. Если полная база ещё не была собрана, интерфейс использует **явно помеченную резервную базу одной группы** (`database_sample_v413.js`). Она нужна только для того, чтобы интерфейс можно было открыть и проверить.

Для всех групп, актуальных аудиторий и полной офлайн-базы сначала запусти `start.bat` или `update_database.bat`.

## Файлы данных

- `database_v413.json` — **полная база**, появляется после успешной сборки и игнорируется Git;
- `database_v413.js` — та же полная база для `file://`, тоже генерируется локально;
- `database_status.json` — статус и статистика последней сборки;
- `database_sample_v413.json/js` — резервный пример только для М9О-217БВ-25, не выдаётся за полную базу;
- `schedules/current/` — временные файлы при полной сборке, по умолчанию удаляются после сжатия.

## Проверка Зверева

Вкладка «Преподаватель» умеет проверять конкретную группу напрямую по свежему JSON МАИ через локальный сервер. Значения по умолчанию:

- группа: `М9О-217БВ-25`;
- преподаватель: `Зверев`;
- период: `01.09.2026–31.01.2027`.

## Если обновление не прошло

`public.mai.ru` должен открываться с твоего компьютера. Если часть запросов временно упала, снова запусти `update_database.bat`. Статистика и первые ошибки записываются в `database_status.json`.
